# 현재 보완 항목

이 문서는 작업 승인이나 자동 구현 목록이 아닙니다. 최신 미해결의 사실·근거·수용 경계는 [KNOWN_ISSUES](KNOWN_ISSUES.md) 한 곳에서 관리합니다.

| 항목 | 다음 확인 | 승인 경계 |
|---|---|---|
| 장시간 관찰 | 기존 실패의 원인·현재 재현 여부를 별도 재확인 | 기존 FAIL 보존, 기준 완화 금지 |
| 장애 전환 사용자 표시 | 기존 유실/receipt/소비자 ACK를 구분하는 표시 범위 설계 | 예정이며 구현 완료 아님 |
| 설정 범위 | 필요한 다른 공통 섹션의 요구·adapter 가능성 조사 | DTCore 변경 전 사용자 승인·별도 검증 |
| 현장 수용 | 직접 UI·회사 서버·실장비 점검 | 로컬 자동화와 구분 |
| 문서 정책 검사 | legacy baseline 실패와 현재 경로의 불일치 정리 | 검사를 약하게 해서 PASS 만들지 않음 |

## DTCore 변경 후보

현재 데이터 채널 연결·등록·상태는 DTCore API로 통합됐습니다. 다른 공통 섹션 loose 재적용은 요청 범위 밖입니다. 추가 공통 변경이 필요하면 프로젝트/DTDevice 우회 불가 근거와 최소안을 먼저 보고하고 승인 전 수정·pin 변경을 하지 않습니다.

이전 상세 백로그는 [원문 보관](archive/IMPROVEMENTS_BEFORE_R56.md)에 그대로 있습니다. 과거 미완료 항목을 현재 완료로 바꾸거나 전체 구현 승인으로 읽지 않습니다.
