# COIL-01d 사진 대조 근거

기준 `86bfb74` / ref6(사용자 제공 300×199 px, ref1과 동일 장면), 보조 ref1·ref4. 시각 비례를 정하며 크레인 구조설계·인증 SWL 자료가 아니다. 원본 사진은 수정하지 않는다.

## 해측 주 다리와 문형 프레임

ref6의 전면 해측 다리 대차 중심은 약 (80,180), 꺾임은 (87,78), 상부 연결은 (115,13) px다. 육측은 대차 (244,183), 상부 (222,0 부근)으로 읽힌다. 상부가 잘렸고 촬영 표정이 없으므로 픽셀 기울기를 실물 경사로 단정하지 않는다. 해측 하부 겉보기 경사는 atan(7/102)≈3.9°, 상부는 atan(28/65)≈23.3°다. 육측 선과 거더 길이 방향은 소실점 영향이 서로 다르다. 사진에서 위쪽으로 좁아지는 문형 투영을 기준으로 한다. 해측 상부는 붐 뿌리 아래까지 이어지는 **주 다리 자체**이며 별도 하부 버팀대가 아니다.

기존 전 높이 2m inset(약4.3°) 대신 Z1.4→16m의 횡 offset0.6m, Z16→28m의 상부 offset 후보3.8/5.0/6.2m를 같은 카메라에서 비교한다. 상부 실물 횡경사는 각각14.93°/20.14°/25.02°다. 육측 상부 inset2m, 기초 X폭8m→상부6.8m, 레일 게이지12m는 유지한다. 좁은 사용자 게이지에서는 횡 inset을 게이지/12로 함께 축소해 다리 역전을 막는다. 실제 설계 치수는 미확인이다.

## 카메라와 판정 경계

안벽 위1.8m, 로컬 (45,QuayOffset(23),Q+1.8)에서 (-8,RailCenterY,Q+17.5)를 본다. 가로 FOV72°로 올려다보며 선박/붐은 화면 왼쪽이다. 크레인 초점 프리셋만68°이며 나머지 뷰의60°는 유지한다. 사진의 초점거리·소실점 미확인으로 동일 카메라 복원은 보장하지 않는다.

레일 중심·양정28m·최대반경35m·선박/해치 치수·작업 범위는 유지한다. 다리·강관 시각 비례와 주 다리 단순 충돌 방향만 변경한다. 하중·간섭·정착·LiDAR 편차·2% 기준과 하부 knee strut 부재 검사를 유지한다.
