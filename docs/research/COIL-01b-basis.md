# COIL-01b — 사진 기준 배치와 수치 근거

조사/구현: 2026-10-22. 새 사용자 ref4·ref5와 r4/r5 피드백을 적용하고, 포털 상세는 ref6을 주 기준으로 ref1·ref4와 대조한다. 기존 [COIL-01 근거](COIL-01-basis.md)의 해석 식·입력 미확인 원칙은 유지한다.

## 선박 선택

기존 R-class의 긴 홀드 수치는 공개 제원과 일치한다. 새 사진의 여러 짧은 해치·갑판 크레인 배치에 맞춰 N-class로 전환한다. ref5의 선명(Crest Navigator)은 [Gard 등록](https://gard.no/vessels/508323/)에서 현재 Naxos/IMO9610224,36,360DWT로 확인된다. 외형 구도를 참고하고, 요청의1~3만DWT 범위에 맞는 별도 선박 제원을 적용한다.

[Wagenborg N-class 공식 제원(2024 PDF)](https://www.wagenborg.com/media/ozfbgtjf/2024-n-class.pdf): DWAT23,000t, LOA174.10m, B22.00m, D12.80m, summer draft9.38m/ballast6.20m, 4개 fully-box/open-hatch/no-understow 홀드와 유압 접이식 해치. 내부 L은24.80/27.40/27.40/24.80m, B18.80m, H14.00m. 탱크톱 등분포14.50t/m². 좌현 갑판 크레인3기(35t@16m). 작업 대상은 선미측 #4,24.80×18.80m이며 다른3해치는 닫힌다. 해치 폭18.8m는 사용자의 예상 범위보다0.8m 넓지만 공개 실치수를 보존했다. 실제 승인 매뉴얼의 개별 제한은 별도다.

표시 흘수는 선사 ballast6.20m를 쓴다. TT/keel0.2m, coaming1.4m, 홀드 간격4m, LBP166m/14kn/AP위치0.25, Δ30000t/KG7/KM9/FSC0.2m는 **합성 배치/해석 입력**이다. 흘수에서 정수력 평형을 계산한 값이 아니며, 원본 GA의 구조/프레임/정수력표가 없음을 자료 필요로 표시한다. HoldHeight14m에 coaming이 포함되도록 표시 갑판은12.6m다. Loading Manual/CSM·국부 허용·ovality·LCF/MCT 미제공은 통과로 처리하지 않는다.

## 커버·크레인·작업 반경

ref4처럼 열린 작업 해치 양끝에 접힌 패널을 세워 표시한다. 접이 패널은 시각 전용 NoCollision, 개구부24.8×18.8m와0.20m 여유는 기존 결정적 판정에 사용한다. 나머지 닫힌 커버는 실제 차폐/충돌 상자다. 갑판 크레인은 좌현에서 선수미로 수납한 모습만 표현하고 하역 기능은 없다. 붐 내측 Y와 개구 외곽의 여유를 계산해 겹치면 경고한다.

부두 포털은 기존 근거§5의 훅 총하중40t, 반경11~35m, 레일 위28m/아래15m, 스팬12m 합성 프리셋을 유지한다. 새 선폭과 레일 위치에서 반경을 계산하고11개 대표 열 배치가 해치·반경·수납 붐을 피하는지 시험한다. 인양 통과 높이는 세운 접이 패널의 높이와 코일 반경/여유를 포함한다. ref4의 훅 블록/리프터는 시각 전용이며, 기본 슬링과 C-hook 선택의 기존 판정은 유지한다.

## 창고 이격과 동선

육측 레일 바깥5m를 대차·계단/난간 여유로 두고,12m(양방향6m씩) 차량 통행로 뒤에 창고 전면을 배치했다. 창고 중심은 추가5m 뒤다. 기본 좌표: 안벽 Y−13m, 육측 레일−28m, 통행로−33~−45m, 창고 전면−45m/중심−50m. 안벽 cradle은 Y−21m로 크레인 반경 안에 남고, 반경3m의 매단 하중 표시 구역은 창고와 겹치지 않는다.

[ILO Safety and health in ports §3.2.1](https://www.ilo.org/sites/default/files/wcmsp5/groups/public/%40ed_protect/%40protrav/%40safework/documents/normativeinstrument/wcms_107615.pdf)은 차량·화물 폭과 조종성을 고려한 도로, 차량/보행 분리와 레일 사이 충분한 통행 폭을 요구한다. 일반 차로5m와 제한 구역의 추가 여유도 안내한다. 여기의5+12m는 이를 참고한 **예제 배치**이며 특정 항만의 현장 승인/선회 궤적 검증이 아니다.

## 외형·렌더 및 비교

노란 다리·박스 거더·브레이스, 대비되는 계단·난간, 흰/노란 운전실·기계실, 트롤리·훅 블록을 표현한다. 창고는 녹색/주황 패널과 열린 전면의 cradle 열,1.8m 신호수를 표시한다. 반복 장식은 NoCollision ISM으로 묶고 거리 cull한다. 외부 선형/거주구는 시각 근사, 측정 기준은 기존 box hold·코일/받침·닫힌 커버다.

새 래스터/텍스처/모듈 없이 기존 M_CoilSurface의 instanced usage flag를 Unreal API로 활성화했다. 재질 그래프·광학 반사율·PCD 계약은 바꾸지 않는다. 단면 HR/CR 색과 실치수 포장선은 UI 투영, 전경색은 별도 MID다. Camera 물리 계측 보정은 이번 범위 밖이다.

UE5.3의 비영점 ViewRect로 생긴 우측/하단 검은 잘림은 full render target을 유지한 off-axis player projection과 소유 UI 마스크로 수정했다. 추가 SceneCapture/readback은 없다. 단면/상면의 기준은 실치수이며 포장선의 raster 선 굵기만 가독성을 위한 표시다. 원본 캡처는 Saved/Reports/COIL-01b/progress, 비교는 quay-ref4-ref5-compare.png에 기록한다.

## ref6 포털 상세 (r6/r7)

사진의 부재 관계를 같은12m 레일 스팬/28m 레일 위 양정 안에 구현했다. 박스 다리4개는 하단1.60m/상단1.088m 단면으로 테이퍼하고, 각 다리에2개씩 총8대차/16차축/32개 휠 면을 배치했다. 바퀴 지름0.82m와 중심 높이는 레일 상단에 맞춘 표시 가정이다. 이퀄라이저·피벗·모터 하우징·버퍼/줄무늬·레일 클램프·스톰 앵커, 장비번호31을 표시한다. 사진만으로 제작 상세 치수를 식별할 수 없어 이 수치는 대표 비례이며 구조 설계/인증값이 아니다.

다리 사이 다단 원형 강관 X/K 브레이스, 상부 문형 프레임을 연결했다. 해측 캔틸레버 밑 knee strut는 r8 사진 대조에서 근거가 없어 제거했다. 육측 레일 바깥 계단탑은8개 지그재그 경사로/랜딩,144개 디딤판, 양측 난간으로 구성하며5m 설비 여유 안에 있다. 거더는 웨브·상하 플랜지·양면 반복 스티프너·엔드캐리지, 양측 통로·난간과 트롤리 레일을 갖는다. 상부 기계실에는 루버/문/지붕, 트롤리에는4휠·2드럼·모터/감속기·시브, 측면에는 행거와 늘어진 페스툰 케이블을 표현했다. 유리창·창틀·접근 사다리/발판이 있는 하부 운전실은 트롤리를 따라 이동한다.

와이어6줄과 다중 시브 훅 블록, 선택형 C-hook/슬링을 표시한다. 부착물 방향은 코일 eye 방향을 따른다. 와이어/드럼 회전과 유압 커버 동작은 상세 동역학 모델이 아니며 기존 해석 진자/경로와 물리 코일 관측을 유지한다. 열린 커버는 양끝2매씩4매, 보강재·힌지·유압 실린더/로드·리프팅 러그를 표시한다. 닫힌 커버는 중성 회색에 패널 이음선/클리트, 갑판 크레인은 밝은 회색 포스트·쌍지브·와이어·운전실/창틀·유압부·수납 훅을 표시한다. 쌍지브 실제 반폭0.37m를 해치 외곽 여유 판정에도 사용한다.

반복 시각 부재는 약2천개를 NoCollision ISM으로 묶고 근접 상세는90~150m에서 cull하여 기존 단순 프레임이 원거리에 남는다. 세부 인스턴스의 그림자를 끄고 별도 측정 캡처/readback을 추가하지 않는다. 바다는 회청/청록 albedo·비금속·높은 roughness로 조정하고 표시 면을 멀리 연장해 유한 평면 끝의 어두운 수평선 띠를 줄였다. 구조/측정 충돌·PCD 기본 송신·노출 정책은 유지한다. 비교 원본과 근접3장은 progress에 별도 보관하고 합성 비교판은 원본의 색/내용을 수정하지 않은 배치다.
