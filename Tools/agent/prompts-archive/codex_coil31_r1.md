1. **장면 ① 하역기 → 선박**: 안벽 cradle의 코일을 레일식 포털 크레인(훅+슬링/C-hook 선택, 기본 ref2의 훅+슬링)으로 들어 해치 통과 → 홀드 목표 위치에 하강·안착. 크레인 SWL·아웃리치·해치 개구부 간섭·매단 하중 흔들림(진자) 표시.
2. **장면 ② 홀드 내부**: 홀드 내부만 보이는 뷰에서 코일을 단계적으로 쌓기. **단수 고정 아님** — 사용자가 계속 쌓을 수 있고, 허용 하중·안정성 등을 넘으면 **경고 표시**(차단하지 말고 경고·사유·수치).
3. 선박: **제품선/일반 화물선 약 1~3만 DWT, 상자형(box-shaped) 홀드**. 실제 제원 비례(조사 근거 기록, 비현실적 크기 금지). 대표: 예) LOA ~150–170 m, B ~23–27 m, 홀드 3~5개, 탱크톱 허용하중 조사값(예 15–25 t/m² 범위, 근거 명시).
4. 코일: **대표 사양 기본값 + UI에서 조절 가능** — 외경(OD), 내경(ID 508/610/762), 폭, 무게(밀도 기반 자동계산 + 수동 오버라이드), 재질 마찰계수, 코일 ID. 대표값: 근거 문서 §2 권장값(OD 1.600, ID 0.762, 폭 1.250 m, ≈14.8 t, 강 밀도 7.85 t/m³ 검증). 코일 목록(CSV/JSON: id,od,id,width,weight) 입력도 지원.

## 핵심 원칙: 가상 검증(해석) → 실제 놓기(물리)
A. **사전 가상 검증(결정적 해석)** — 배치 전 고스트 미리보기로 판정:
- 탱크톱/하단 코일 지지 하중(받침목 접촉 면적 기반 t/m²) vs 허용 하중
- key/locking coil 기하: 상단 코일이 하단 두 코일 사이 골에 안정 안착하는 조건(OD·간격·접촉각), 미끄럼/구름 위험
- 하단 코일 변형(ovality) 위험: 단수별 상부 하중 vs 코일 강성 근사(근거·한계 명시)
- 마찰 콘/정적 평형, 선박 운동 가속도(IMO CSS Code Annex 코일 고정, P&I 코일 적재 가이드 조사·인용) 기준 이탈 위험
- 선박 영향 간이: 적재 무게중심 상승, 횡경사(list)/트림 — 경고 수준 표시
- 해치 개구부/코밍/크레인 SWL·아웃리치 간섭
B. **실제 놓기(Chaos 물리)** — 하강·안착 후 정착(settling), 미끄러짐·구름·전도 감지. 이후 **선박 운동 시험**(roll/pitch 진폭·주기 프리셋, CSS 기준 가속도 수준)으로 변위 임계 초과 시 "이상" 표시. 해석 판정과 물리 결과 나란히 비교 표시. Chaos 비결정성·원통 충돌 근사 한계는 문서화하고, 판정의 기준은 해석, 물리는 확인용.

## 추가 고려 (사용자: "추가 고려 사항도 감안")
- 적재 방향: 기본 eye 선수-선미 방향(fore-and-aft), 받침목(dunnage) 위 열 배치, 쐐기(chock)·key coil·래싱 유무를 판정에 반영(래싱 와이어 정밀 모델은 v1 범위 밖, 플래그로).
- 코일 손상 위험: 모서리 접촉/강재끼리 직접 접촉 경고.
- 작업 안전: 매단 하중 하부 작업자 금지구역 표시(ref2 신호수 맥락), 풍속 프리셋에 따른 흔들림.
- 센서 디지털 트윈: GPU LiDAR로 실제 코일 위치 측정 → 계획 대비 편차 표시, 코일 semanticLabel=Coil + 코일 ID(기존 Slab 라벨 방식). 출력 정책: PCD 기본 송신 유지.
- 적재 계획 저장/불러오기(SaveGame/JSON), 단계 되돌리기(Undo).
- 성능: 60 FPS 근처, 코일 수 수백 개에서도 동작(인스턴싱), LiDAR 20 Hz 유지 목표.
