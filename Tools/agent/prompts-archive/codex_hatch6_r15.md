1. **메모리(RSS) 해결** — 기준(원래 8 MiB 절대, 50회−0회 차이 8 MiB) 유지, 완화 금지.
   - 현재: 50회 RSS 5.25/8.15/7.88 MiB, 차이 9.49/9.03/6.34 MiB, RHI proxy 재생성 0·버퍼 크기 불변.
   - 측정 잡음 줄이기와 진짜 원인 분리를 함께: 반복 수(예: 5쌍 이상)·순서 교차로 분산 추정, 50회 동안 시점별 RSS 곡선(퍼내기 횟수에 비례하는 기울기 vs 계단/포화) 기록. 기울기가 있으면 원인 후보(퍼내기 시 메시 섹션 재빌드·충돌 쿠킹/스냅샷 재생성·높이장 텍스처·히트맵/단면 텍스처 재업로드·그랩 애니메이션 리소스·파티클/미스트·Slate 브러시·로그/JSON 누적·UObject 생성)를 LLM 태그·memreport·RHI 리소스 수·UObject 수로 하나씩 배제하며 수정(풀링·in-place 갱신·재사용).
   - 결과: 기울기 0(포화) 입증 + 절대/차이 기준 통과가 목표. 해결 못 하면 근거(곡선·분산)를 DONE.md 맨 위에.
