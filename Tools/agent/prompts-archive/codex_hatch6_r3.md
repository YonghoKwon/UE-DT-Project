사용자 원문: "선박과 하역기의 크기가 너무 사실적이지 않게 하지 말아줘!" (= 비현실적인 크기로 만들지 말 것, **실제 크기·비례를 지킬 것**)
요구:
- 선박: 홀드(폭 42.3 · 길이 25.8 · 깊이 22.5 m)에 맞는 실제 벌크선 치수(예: 케이프사이즈급 LOA ~290–300 m, 선폭 ~45–47 m, 형심 ~24–25 m, 홀드 9개 내외, 해치 개구부 실제 비례)로. 웹 검색 가능하면 대표 선형 제원 출처를 RESULT에 기록.
- GTSU 하역기: 실제 그랩식 연속하역기 제원 비례(예: 정격 1,500–2,500 t/h급, 레일 스팬 ~22–30 m, 해측 붐 아웃리치 ~35–45 m, 붐 높이·그랩 용량 등) — 대표 제조사/항만 제원 근거 기록. 선박·안벽·하역기 상대 위치(안벽 높이, 흘수, 붐이 해치 중앙까지 닿는 아웃리치)가 맞게.
- 사람 크기 기준물(작업자 1.8 m)이나 스케일 막대를 3D에 선택 표시해 크기 감을 확인 가능하게(기본 꺼짐).
- 센서 장착 위치(붐 끝 1, 운전실 2)와 커버리지는 실제 치수 기준으로 재계산·표시.
- 자동 검사: 주요 치수(선폭·LOA·형심·레일 스팬·아웃리치·운전실 높이)가 설정 범위 안인지.
