## #29 해치 코너 근접 화면 사실감 (사용자 승인)
기준 이미지: Saved/Reports/GPU-LIDAR-01/captures/corners/corners-sheet.png (현재 문제), 참고 사진 Saved/Reports/HATCH-06/reference/ (ref4 최우선).
1. **노출/원료 색**: 근접 시 자동 노출이 밝아져 철광석이 분홍빛 베이지, 석탄이 밝은 청회색으로 보임. 실제: 철광석 어두운 적갈색~회흑색(분광/펠릿 혼합), 석탄 거의 흑색(약한 광택). 해치 뷰 카메라에 노출 범위 고정/보정(PostProcess, 측정 데이터 무관) + 원료 albedo/roughness를 실측 수준 반사율(철광석 albedo ~0.08–0.15, 석탄 ~0.03–0.05)로 조정. 원거리·조감 화면도 같이 확인해 과도하게 어두워지지 않게.
2. **코밍/벽 조명·디테일**: 붉은 코밍이 단색 평면 — 코너 앰비언트 오클루전/그림자 대비, 도장 마모·녹·원료 분진 얼룩(머티리얼 파라미터/버텍스 컬러, 절차적) 추가. 장식은 NoCollision, 측정 스냅샷 제외 유지.
3. **만재 표면 형상**: 만재 원료가 평면에 가까움 — 안식각(철광석 ~35–40°, 석탄 ~35°) 기반 완만한 둔덕/벽쪽 경사·그랩 자국을 초기 높이장에 반영. 이는 측정 대상 표면이므로 CPU/GPU 측정·디깅·체적 계산과 일관되게(높이장 자체를 바꾸는 것), 기존 체적/만재율 테스트는 기대값을 낮추지 말고 새 형상에 맞춰 근거와 함께 갱신.
4. 비교: 같은 6개 코너 시점 before/after 합본(corners-before-after.png).
- RT on, GPU LiDAR 20Hz·60FPS 퇴행 없음.
