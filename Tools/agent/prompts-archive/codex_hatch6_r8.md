사용자 원문: "그랩이 너무 없어 보여(=조잡해 보여)... 그냥 그랩에 대해서 On/Off 해서 안 보이는 채로 퍼내기 되도록 해줘. 추가로 그랩 모델링에 대해 위 첨부 이미지 참조해서 좀 더 힘을 써줘."

1. **그랩 표시 On/Off**: 상단 툴바(또는 퍼내기 조작 영역)에 "그랩 표시" 토글. Off면 그랩·로프·하강/배출 애니메이션을 그리지 않고 **퍼내기는 즉시 그대로 동작**(함몰·재측정·지표 갱신). 기본값은 근거 기반(시연용으로 품질이 확보되면 On, 아니면 Off — 결정 근거 기록). Off일 때 그랩 차폐도 측정에서 제외(그랩이 안 보이면 센서 시야도 가리지 않음 — 일관성), 히트맵 미관측 원인도 그에 맞게 갱신.
2. **그랩 모델링 품질 향상** (첨부 ref2·ref3 참조, 사본 `Saved/Reports/HATCH-06/reference/ref2-grab-hopper.jpg`, `ref3-clamshell-hold.jpg`):
   - 클램셸 2쉘: 각 쉘은 측판(반원/사분원 형상)+바닥 곡면+립(날)과 보강 리브, 두 쉘이 중앙 힌지 축에서 맞물림. 상부 헤드(크로스헤드/시브 블록) 박스와 하부 시브, 쉘과 헤드를 잇는 **4개의 암(타이 로드)**, 홀딩·클로징 로프 4가닥(또는 체인). 열림/닫힘 각도에 따라 암·쉘이 기구학적으로 연동.
   - 비례: 실제 그랩(용량 수십 m³급, 폭·높이 근거) 기준, 하역기 제원과 정합. 저폴리 절차 메시지만 실루엣이 사진처럼 읽히도록 엣지 베벨/노멀, 도장(회색 강재·마모 흔적·원료 묻음) 머티리얼 파라미터.
   - 배출 장면(ref2): 열린 쉘 아래로 원료가 쏟아지는 흐름(가벼운 파티클/카드)과 미스트.
   - 성능: 그랩 메시 1개 인스턴스, 그리기 비용 측정·기록, 150 ms 초과 0 유지.
