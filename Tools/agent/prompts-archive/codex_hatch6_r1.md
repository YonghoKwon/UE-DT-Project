[Claude → Codex 추가 지시 · 같은 세션 이어서] HATCH-06 추가 요구 5 (사용자 2026-10-21)

사용자 원문: "원료를 홀드 밑 바닥까지 퍼내면 바닥이 보여야 하는데... 현재는 바닥이 보이지 않는 거 같아... 이 부분도 수정해줘!"
HATCH-04에서 "바닥 노출"을 구현·자동 검증했다고 보고했지만 **사용자 실제 화면에서는 여전히 바닥이 안 보인다**. 자동 검사(높이 0·탱크톱 충돌)가 실제 렌더 결과를 보장하지 못했을 가능성이 높다.
요구:
- 실제 렌더에서 재현: 한 지점을 반복 퍼내기(기본 반경·깊이)로 바닥까지 → 일반 3D·3D 점군·단면 캡처로 홀드 바닥(탱크톱 강판, 원료와 구분되는 색/질감)이 실제로 보이는지 확인. 원인 후보: 원료 메시 하한 클램프가 바닥보다 위(최소 두께 잔존), 바닥 메시가 없거나 원료와 같은 색/z-fighting, 원료 메시가 바닥을 덮는 스커트/측면, 퍼내기 깊이 누적 제한, 높이장 해상도 대비 반경, 점군이 바닥 hit를 원료 색으로 칠함, 카메라 각도상 측벽에 가림, HATCH-06 원료 디테일 노이즈가 0 두께에 다시 높이를 더함.
- 수정: 두께 0 영역에서는 원료 표면을 그리지 않거나 바닥 아래로 내림(z-fighting 없게), 바닥은 탱크톱 강판 질감(녹·용접선 느낌, 원료와 확실히 다른 색)으로, 점군 분류 색도 바닥 별도. 원료 디테일 노이즈는 두께에 비례(0이면 0).
- 검증: **렌더 픽셀 기반 자동 검사**(퍼낸 영역 중심 화면 좌표의 색이 바닥 색 범위) + 캡처 전/후를 `progress/`에 저장해 Claude가 확인. 철광석·석탄 모두.
나머지 HATCH-06 요구·원칙·운영·검증·금지는 기존 지시 그대로. 중단 시점의 작업 트리 변경을 이어서 사용할 것.
